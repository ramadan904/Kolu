🏆 Grand Prize · Build with DataHub

Project Blackbox

by Alex Velazquez

An autonomous data incident response agent. It takes plain-English anomaly reports, traces them back to their root cause using DataHub lineage, automatically repairs the broken code, and opens a pull request that includes machine-verified proof of the fix.

🏆 Overall Winner · ARM Create

Literally the Smallest 0.5B Param Functional LLM ever built

by Bitan Nath and Swati Ram

A 0.5 billion parameter LLM that runs at ~3 tokens per second on an Apple Watch using only 64 MB of peak RAM. Built in Zig using ARM NEON SIMD instructions and memory mapping (mmap) — the first publicly working multi-turn conversation LLM on wearable hardware, including a mood-uplifting agent demo.
